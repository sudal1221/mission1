# 내 영화 티어리스트

## 1. 누가 쓰나

- 나와 영화를 좋아하는 친구들
- 자신이 본 영화를 등급별로 정리하고 취향을 공유하고 싶은 사람

## 2. 무엇을 하려고

- 내가 본 영화를 S·A·B·C의 4단계로 분류하여 영화 취향을 정리합니다.
- 친구들과 영화에 대한 평가와 감상을 비교하고 이야기할 수 있도록 합니다.

**영화 등급 기준**
- **S등급:** 인생 영화
- **A등급:** 정말 재미있는 추천 영화
- **B등급:** 볼 만한 영화
- **C등급:** 아쉬웠던 영화

## 3. 화면과 동작

- 화면 위쪽에 S·A·B·C의 4개 등급 칸을 배치하고, 아래쪽에는 아직 분류하지 않은 영화 카드를 보여 줍니다.
- 영화 카드를 마우스로 끌어서 원하는 등급 칸에 놓거나, 카드를 클릭한 후 등급 버튼을 눌러 이동할 수 있습니다.
- 영화 제목을 입력하고 '추가' 버튼을 누르면 미분류 영역에 새로운 영화 카드가 생성됩니다.
- 영화 목록과 등급 배치는 브라우저에 자동 저장되어, 같은 브라우저에서 페이지를 다시 열어도 유지됩니다.
- '처음으로' 버튼을 누르면 추가한 영화와 기존 등급 배치가 초기화되고, 최초 영화 8개가 모두 미분류 상태로 돌아갑니다.

## 4. 필요한 자료

처음 제공할 영화는 총 8편입니다.

1. 기생충
2. 인터스텔라
3. 라라랜드
4. 센과 치히로의 행방불명
5. 어벤져스: 엔드게임
6. 범죄도시
7. 타이타닉
8. 토이 스토리

## 5. 완성 기준

- S·A·B·C의 4개 등급 칸과 미분류 영역이 화면에 표시됩니다.
- 영화 카드를 드래그하거나 클릭하여 원하는 등급으로 이동할 수 있습니다.
- 각 영화는 한 번에 하나의 등급 칸 또는 미분류 영역에만 존재합니다.
- 제목을 입력하고 '추가' 버튼을 누르면 새로운 영화 카드가 생성됩니다.
- 빈칸이나 공백만 입력하면 카드가 생성되지 않고 입력 안내가 표시됩니다.
- 영화를 분류하거나 추가한 내용은 자동 저장되며, 같은 브라우저에서 다시 열어도 유지됩니다.
- '처음으로' 버튼을 누르면 저장된 변경 사항이 초기화되고 최초 영화 8개가 모두 미분류 상태로 돌아갑니다.
- 컴퓨터와 모바일 등 화면 크기가 달라도 내용이 잘리지 않고 표시됩니다.
- 별도의 로그인이나 서버 실행 없이 HTML 파일 하나로 실행할 수 있습니다.
